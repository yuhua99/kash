# Component Name

## Usage

```vue
<script setup>
import { ComponentName } from '@/components/ui'
</script>

<template>
  <ComponentName>Example usage</ComponentName>
</template>
```

## Props

| Prop       | Type   | Default   | Description             |
| ---------- | ------ | --------- | ----------------------- |
| `propName` | `type` | `default` | Description of the prop |

## Events

| Event       | Payload | Description                              |
| ----------- | ------- | ---------------------------------------- |
| `eventName` | `type`  | Description of when the event is emitted |

_If no events, write "None"_
